# C语言数字 PID 控制器仿真

## 项目描述
用纯 C 语言实现了一个数字 PID 控制器，并对一阶惯性被控对象进行闭环仿真。本项目旨在从底层代码理解比例(P)、积分(I)、微分(D)三种控制律对系统动态响应的影响。

## 核心公式
- **被控对象 (离散化)：** `y[k] = 0.8 * y[k-1] + 0.2 * u[k-1]`
- **控制律：** `u[k] = Kp*error + Ki*∑error + Kd*(error - prev_error)`
- **目标值：** 1.0

## 仿真结果
控制器参数 Kp=1.2, Ki=0.3, Kd=0.1 时，系统在 20 步左右快速收敛到目标值，无超调，稳态误差接近 0。
